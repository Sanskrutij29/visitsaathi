# VisitSaathi

Spot the gaps in your parent's hospital visit before the day.

VisitSaathi is a product concept for adult children who coordinate a parent's
hospital visits from another city. It checks who is helping at each stage of
the visit, what happens if the visit runs late, and who brings the parent home.

## This repo
- `index.html`: single-page landing page (HTML, CSS and inline SVG illustrations)
- Hosted on Vercel
